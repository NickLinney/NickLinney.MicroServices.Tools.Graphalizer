# Releasing

The first planned release vehicle is `release/pre-alpha/1`; the planned tag is `0.0.0-pre-alpha.1`.

Sprint 1 is not a release event. Do not merge to `main`, create a tag, publish a GitHub Release, or represent the development image as accepted.

A later authorized release requires a clean exact candidate, complete acceptance evidence, dependency/license inventory, matching version documentation, independent QA and Security/Ops dispositions, Sponsor acceptance, and Release Manager authorization.
