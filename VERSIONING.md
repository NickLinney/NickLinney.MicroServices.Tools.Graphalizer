# Versioning

The project uses Semantic Versioning 2.0.0 plus the NickLinneyDev pre-alpha convention.

- Development work is reported as `0.0.0.dev0` and must be bound to a commit SHA.
- The first feature-complete MVP draft targets `0.0.0-pre-alpha.1`.
- Pre-alpha tags are immutable snapshots.
- Version changes occur only during an authorized release event with matching release notes and changelog updates.
